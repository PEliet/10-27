# 《这破能力也能赢？》

一款三关制中文卡牌策略小游戏。每局抽取一种超能力，使用四张行动卡处理公开的目标与威胁。数值和胜负由游戏规则结算。

## 运行方式

需要安装 Node.js 20 或更新版本（包含 npm）。在项目目录打开终端：

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，通常是 <http://127.0.0.1:5173>。

- Windows：双击 `start.bat`，脚本会检查环境、首次安装依赖并启动游戏。
- macOS/Linux：首次运行 `chmod +x start.sh`，之后执行 `./start.sh`。

不能直接双击 `index.html` 运行。

## 基本玩法

1. 点击“抽取超能力”。每种能力都有被动效果、每关可用的主动技能和对应的卡牌协同。
2. 正式 AI 模式需要先打开“模型设置”，填写自己的 API 地址、Key 和模型名称，再保存使用。AI 会设计本局三关；需要真实 AI 调用时会产生服务商用量费用。
3. 不配置模型也可以选择“离线示例局”体验完整游戏。离线示例使用固定蓝图，不是实时 AI 生成。
4. 每回合有四张行动卡，点击卡牌即可行动。留意当前目标、进度、威胁意图、能量、护盾和机巧，再决定出牌顺序。
5. 点击“结束回合”后，公开的威胁才会结算。达到关卡进度目标即可通关。
6. 关间可以选择卡牌奖励、超能力成长，以及恢复生命或升级卡牌。三关结束后可以查看、下载战绩卡或复制战报。

游戏进度保存在当前浏览器中。需要 AI 时请使用自己的 API Key；Key 默认只在当前页面内存中，刷新后需要重新输入。选择“记住到本机”会将 Key 保存到当前浏览器。
